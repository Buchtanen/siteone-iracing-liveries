# McLaren 720S GT3 EVO — SiteOne Light V7

Verze schválená k exportu 5. 10. 2026. Pro Trading Paints použijte:

- **paint.tga** — celý paint včetně patternu, log a nápisů, 2048 × 2048, RGB 24-bit RLE.
- **spec.mip** — odpovídající materiálová mapa vytvořená iRacingem.

Samostatný decals soubor nepřidávejte. Varianta Sim-Stamped Number, bez vlastních závodních čísel.

Světlý styl SiteOne přizpůsobený liniím a UV McLarenu 720S GT3 EVO. Aktuální loga bez .cz a správný pattern jedniček. Šedé a červené prvky na tmavých bocích, malé logo uvnitř průduchu kapoty a větší nápis SiteOne. Celé červené skořepiny zrcátek a přední aerodynamická křidélka. Pět žeber na každém předním blatníku odstupňovaných od světle šedé vpředu po tmavou vzadu. Spec mapa odpovídá posledním úpravám.

`preview.png` je aktuální UV textura. Starší studiové ilustrace a PDF katalog předcházejí V7.

## Pracovní zdroje


Aktuální archiv `sources-psd.zip` obsahuje editovatelný paint PSD, materiálový PSD, zdrojovou spec mapu, paint a decals vrstvy i údaje o této verzi.
