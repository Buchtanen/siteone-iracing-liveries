# Ferrari 488 GT3 Evo 2020 — SiteOne Light V4

- **paint.tga** — kompletní paint včetně log a nápisů, 2048 × 2048, RGB 24-bit.
- **spec.mip** — odpovídající materiálová mapa vytvořená iRacingem z finálního zdroje V4.
- **sources-psd.zip** — aktuální vrstvený paint-working.psd, materials.psd, základní paint, samostatná průhledná vrstva log, zdrojová spec TGA a popis UV.

Pro Trading Paints nahrajte paint.tga a spec.mip. Loga jsou součástí paintu; samostatný decals soubor není pro tento export potřeba. Varianta Sim-Stamped Number, původní rezervy čísel zachované.

Finální V4: upravené pozice log na kapotě, skle a obou bocích, schválený nápis na křídle, užší zadní claim. Malá boční loga jsou snížená společně s potlačením patternu.
