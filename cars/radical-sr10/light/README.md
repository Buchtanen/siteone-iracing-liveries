# Radical SR10 — SiteOne Light V4

- **paint.tga** — kompletní paint včetně log a nápisů, 2048 × 2048, RGB 24-bit.
- **spec.mip** — odpovídající materiálová mapa vytvořená iRacingem.
- **sources-psd.zip** — aktuální vrstvené PSD, základní paint, samostatná vrstva log a zdrojová spec TGA, mapa dílů a švů.

Pro Trading Paints nahrajte paint.tga a spec.mip. Samostatný decals soubor není potřeba. Zachované rezervy pro Sim-Stamped Number.

Aktuální SiteOne bez .cz, správná geometrie patternu, malé symboly na přídi, krytu motoru a bočnicích křídla. Šedočervené prvky na tmavých bocích a nová materiálová mapa. V4 zahrnuje schválené posuny nápisů a malých log; na krytu motoru jsou loga mírně vzadu a výš včetně potlačení patternu.
