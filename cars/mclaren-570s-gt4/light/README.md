# McLaren 570S GT4 — SiteOne Light V78

Schválená verze 5. 10. 2026. Tři samostatné soubory pro Trading Paints:

| Soubor | Umístění při uploadu |
|---|---|
| `paint.tga` | Hlavní paint: základní lak, grafika a pattern |
| `decals.tga` | Custom decal layer: loga, velké motivy a firemní claim; průhledné pozadí |
| `spec.mip` | Spec map: materiály a odlesky, vytvořeno iRacingem z odpovídající V78 |

Vyberte McLaren 570S GT4 a Sim-Stamped Number. Závodní číslo doplňuje iRacing. Nahrajte všechny tři soubory z tohoto balíčku. Zdrojové spec TGA a PSD patří do pracovních podkladů, pro spec upload použijte MIP.

V78 obsahuje oddělená SiteOne loga, čtverec s jedničkou na kapotě a obou bocích, firemní claim vlevo vzadu, sjednocenou grafiku zadních boků a doplněný pravý pattern. Velká červená jednička z kapoty byla odstraněna. Spec neobsahuje siluety log.

`sources-psd.zip` v GitHub složce obsahuje paint-working.psd, decals-working.psd, spec-working.psd, spec-source.tga a vektorový claim. Ve zdrojovém paint PSD jsou skupiny PAINT + PATTERN, DECALS a skrytý wireframe.
